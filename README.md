# Elementos de Inteligencia Artificial

Materiales de la asignatura Elementos de Inteligencia Artificial, 4.º año de Ciencia de Datos (curso 2026-2027).

Métodos clásicos de IA (búsqueda, restricciones, planificación, modelos probabilísticos, metaheurísticas) y la
práctica del aprendizaje automático: límites teóricos, datos problemáticos, evaluación y ciclo de vida de los modelos.

La [guía del curso](guia-del-curso.pdf) explica cómo funciona la asignatura.

## Contenido

- [`conferencias/`](conferencias/): notas de las conferencias C1–C8, en Markdown y PDF.
- [`clases-practicas/`](clases-practicas/): enunciados, notebooks y datos de las clases prácticas.
- [`proyectos/`](proyectos/): enunciado del Proyecto 1 (rover autónomo) y su código de referencia.
- [`bibliografia.txt`](bibliografia.txt): bibliografía del curso.
